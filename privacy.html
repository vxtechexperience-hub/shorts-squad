Privacy Policy

Last updated: November 12, 2026

Shorts Squad is a desktop application for Windows that runs on the creator's own computer. This policy explains what data it uses and where that data stays.

What data the app uses

  • Account access tokens from the platforms the creator connects (YouTube, TikTok, Instagram, Facebook), obtained through each platform's official OAuth login.
  • Basic TikTok account information: only the display name and open ID (scope user.info.basic), used to show which account is connected.
  • Video files created by the app on the creator's computer, uploaded only to the creator's own accounts. On TikTok, videos are uploaded to the creator's inbox as drafts (scope video.upload).
  • Public statistics of the creator's own published videos (views, likes, comments), used only to improve which clips the app suggests.

Where data is stored

Everything stays on the creator's computer. Tokens are stored encrypted with the operating system's secure storage (Windows, through Electron safeStorage). Shorts Squad has no server and does not keep a copy of any data elsewhere.

Sharing

The app does not sell, rent or share data with third parties. Data is sent only to the platform the creator chose (for example, a video file is sent to TikTok when a draft is uploaded).

Deleting data

Disconnecting an account in the app's Settings deletes its tokens from the computer. Access can also be revoked in each platform's settings (on TikTok: Settings and privacy → Security and permissions → Apps and services). Uninstalling the app and deleting its data folder removes everything.
